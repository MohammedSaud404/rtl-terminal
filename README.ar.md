## لماذا؟

يعرض Claude Code الردود العربية كما تُعرض لغة تُقرأ من اليسار: كل سطر ملاصق للجهة اليسرى، ونقاط القوائم وأرقامها على اليسار، والأقواس معكوسة، وأي سطر يبدأ بكلمة إنجليزية ينقلب ترتيبه بالكامل.

يرتّب rtl-terminal كل فقرة تُكتب من اليمين إلى اليسار كما يرتّبها المتصفح:

- **أسطر محاذاة إلى اليمين**، تقسّمها الإضافة بنفسها كي يحافظ كل سطر على اتجاهه مهما طالت الفقرة.
- **نقاط القوائم وأرقامها وعلامة الاقتباس على اليمين**، حيث يبدأ القارئ.
- **أقواس في اتجاهها الصحيح**، حتى لو كُتبت معكوسة بلوحة مفاتيح عربية مثل `)هذا(`.
- **الأكواد والأوامر والروابط تبقى من اليسار إلى اليمين** كوحدة واحدة مقروءة داخل الجملة.
- **الرموز التعبيرية بعرضها الحقيقي**، فلا تغطّي رموز مثل ❤ و⚠ الحرف المجاور.
- **رسائلك أنت أيضًا**، مع معاينة حيّة لما تكتبه فوق مربع الإدخال.

تبقى كتل الأكواد والجداول والردود الإنجليزية كما يعرضها Claude Code تمامًا. ويتغيّر العرض فقط: يقرأ Claude نصّك وردوده كما كُتبت.

## التثبيت

نفّذ هذا الأمر داخل Claude Code:

</div>

```
/plugin install rtl-terminal --marketplace MohammedSaud404/rtl-terminal
```

<div dir="rtl">

ثم اكتب `y` لإضافة الـ marketplace، واختر نطاق المستخدم (user scope). تعمل الإضافة فورًا وفي كل جلسة جديدة.

تتطلب Claude Code بالإصدار 2.1.294 أو أحدث. ويشرح [دليل التثبيت](docs/INSTALL.ar.md) التثبيت من سطر الأوامر والتحديث والإزالة وحل المشكلات.

إذا كانت rtl-terminal مثبّتة لديك من مصدر آخر، كبرنامج تثبيت يضمّها معه، فأزِل تلك النسخة قبل التثبيت، لأن Claude Code لا يشغّل إلا النسخة التي ثُبّتت قبل غيرها. اعرف اسمها بالأمر `claude plugin list`، ثم أزِلها بالأمر `claude plugin uninstall` متبوعًا باسمها (مثلًا `claude plugin uninstall rtl-terminal@launchpad-plugins`).

## الاستخدام

تعمل الإضافة تلقائيًا. وتغيّر سلوكها هذه الأوامر، ويُحفظ كل اختيار بين الجلسات:

| الأمر | الوظيفة |
| --- | --- |
| `/rtl` | تشغيل الترتيب من اليمين أو إيقافه |
| `/rtl on` · `/rtl off` | تشغيله، أو إيقافه |
| `/rtl input on` · `/rtl input off` | إظهار المعاينة الحيّة فوق مربع الإدخال أو إخفاؤها |
| `/rtl mode auto` · `claude` · `terminal` | تحديد من يرتّب الأسطر؛ `auto` يكتشف ذلك تلقائيًا |

## أين تعمل؟

| الطرفية | النتيجة |
| --- | --- |
| Windows Terminal وconhost | ✅ ترتيب كامل |
| طرفية VS Code المدمجة على Windows وmacOS وLinux | ✅ ترتيب كامل |
| Terminal.app على macOS وmlterm | ➖ تتولّاها الطرفية: الأسطر التي تبدأ بحرف عربي تظهر صحيحة |
| GNOME Terminal وKonsole | ➖ تتولّاها الطرفية: كل سطر يُعرض من اليسار إلى اليمين |
| xterm | ❌ لا تدعم الطرفية نفسها الكتابة من اليمين |

**سبب الاختلاف:** في Windows Terminal وconhost وطرفية VS Code يرتّب Claude Code النص العربي بنفسه، وهذه هي الخطوة التي تتحكم بها الإضافة. أما في بقية طرفيات macOS وLinux فيترك Claude Code الترتيب لمحرّك الطرفية، ويحذف علامات الاتجاه القياسية قبل أن تصل إليه، فلا توجد طريقة معتمدة لإيصال الاتجاه إليه. لذلك تتنحّى الإضافة هناك ولا تغيّر شيئًا. وقد تحقّقنا من كل سطر في هذا الجدول أثناء التطوير بلقطات شاشة من طرفيات حقيقية على Windows وmacOS وLinux.

## كيف تعمل؟

بدل كتابة قواعد يدوية، تطبّق الإضافة **خوارزمية Unicode الرسمية للنصوص ثنائية الاتجاه** (UAX #9)، وهي نفسها التي تستخدمها المتصفحات، عبر مكتبة [bidi-js](https://github.com/lojjic/bidi-js). تجتاز المكتبة كل حالات اختبار Unicode الرسمي `BidiCharacterTest.txt` البالغة **91,707** حالة، ويعيد الأمر `node scripts/conformance.mjs` تشغيل هذا الاختبار.

لكل فقرة تُكتب من اليمين، تقوم الإضافة بما يلي:

1. تحسب مستوى كل حرف للفقرة كاملة، مع عزل الأكواد والروابط من اليسار إلى اليمين كما يعزل المتصفح وسم `<code>`.
2. تقسّم الفقرة إلى أسطر تناسب عرض الطرفية، وتقيس كل حرف كما يقيسه Claude Code، بما في ذلك الرموز التعبيرية المركّبة.
3. تثبّت كل جزء من السطر بين علامتين غير مرئيتين باتجاهه (RLM أو LRM)، وتعكس الأقواس في المستويات اليمينية، فيصل ترتيب Claude Code المبسّط إلى النتيجة القياسية بالضبط.
4. تعرض الأسطر محاذاة إلى اليمين، مع النقاط والأرقام على اليمين.

## الخصوصية والأمان

لا تغيّر rtl-terminal إلا طريقة عرض النص على شاشتك.

- **لا ترسل شيئًا.** لا تتصل بالإنترنت، ولا تشغّل أي أوامر، ولا تقرأ الملفات أو تكتبها، ولا تجمع أي بيانات استخدام.
- **تقرأ** النص الذي يسلّمه Claude Code لعرضه (الردود، ورسائلك، ومسودتك في مربع الإدخال من أجل المعاينة)، لترتيبه على الشاشة فقط، إضافة إلى متغيرات البيئة `OS` و`TERM_PROGRAM` و`WT_SESSION` و`TERMINAL_EMULATOR` و`FORCE_HYPERLINK`، لمعرفة الطرفية التي تعمل فيها وهل تعرض روابط قابلة للنقر.
- **تحفظ** إعداداتها الثلاثة فقط (التشغيل والإيقاف، والمعاينة، والوضع) في مساحة تخزين الإضافات الخاصة بـ Claude Code على جهازك.
- **شيفرتها مقروءة بالكامل**، بما في ذلك الشيفرة الأصلية لمكتبة [bidi-js](https://github.com/lojjic/bidi-js) دون تعديل، ولا تنزّل أي شيء عند التثبيت أو التشغيل.

### ما الذي تعترضه الإضافة

- `ui.render` لردود Claude ورسائلك والشريط فوق مربع الإدخال: ترسم الفقرات العربية مرتّبة، وتضع المعاينة تحت ما يعرضه Claude Code والإضافات الأخرى في الشريط، وتترك كل ما عداها لـ Claude Code.
- `prompt.edit`: تقرأ مسودتك بعد كل تعديل لرسم المعاينة، ويمضي التعديل نفسه دون أي تغيير.
- `prompt.submit`: تمسح المعاينة عند الإرسال، وتمضي رسالتك دون أي تغيير.
- `command.run`: تجيب عن أمرها `/rtl` فقط، ولا شيء غيره.
- `session.start`: تحمّل إعداداتها، وتضيف الأمر `/rtl`، وتفحص مربع الإدخال كل 0.3 ثانية ما دامت المعاينة ظاهرة، كي تختفي المعاينة مع مسح المربع.

## أسئلة شائعة

**عند نسخ رد يظهر النص مبعثرًا.**
التحديد بالماوس ينسخ ما يظهر على الشاشة، والشاشة تحمل النص بترتيب العرض. استخدم أمر `/copy` في Claude Code بدلًا من ذلك: فهو ينسخ النص الأصلي للرد بترتيب القراءة.

**لماذا المعاينة فوق مربع الإدخال وليس داخله؟**
لا تستطيع الإضافات إعادة رسم مربع الإدخال، وأي شيء يُضاف إلى نصه يُرسل مع رسالتك. لذلك تعرض المعاينة مسودتك مرتّبة دون أن تمسّ ما يُرسل.

**هل تعمل في تطبيق Claude لسطح المكتب أو لوحة إضافة VS Code؟**
ليس بعد. تحتاج هاتان الواجهتان إلى خيار لاتجاه النص في واجهة الإضافات، وقد طُلب في [anthropics/claude-code#99956](https://github.com/anthropics/claude-code/issues/99956) و[#78625](https://github.com/anthropics/claude-code/issues/78625).

## قيود معروفة

- لا يعرض Windows Terminal محرف عدم الوصل (ZWNJ)، فتظهر كلمات فارسية مثل «می‌کند» بالشكل «میکند».
- النص العربي المتداخل داخل كود إنجليزي داخل فقرة عربية يُعرض تقريبيًا، لأن Claude Code يرتّب بمستويين فقط.
- واجهة الإضافات في Claude Code ما زالت في مرحلة الوصول المبكر، وقد تحتاج الإضافة إلى تحديث مع الإصدارات القادمة.
